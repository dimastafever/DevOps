# алвс4 — Настройка HTTP-сервера

## Что находится в файле

Файл `алвс4.docx` содержит материалы по настройке **HTTP-сервера** — службы, которая обслуживает
веб-запросы клиентов по протоколу HTTP. В файле отражён процесс перехода от «просто страницы»
к полноценному серверному развёртыванию.

Содержимое файла (ключевые фрагменты):

```
1
2
http
Переделал под сервер всё работает
Перезапускаем и работаем
Делаем с 1 клиента
Поменяли hosts и всё супер
3
s
4
```

Ключевые элементы:

| Элемент | Описание |
|---------|----------|
| `http` | Протокол передачи гипертекста |
| `Переделал под сервер всё работает` | Перенастройка конфигурации с целью работы серверной части |
| `Перезапускаем и работаем` | Перезапуск службы после изменений |
| `Делаем с 1 клиента` | Проверка работы с одного клиента |
| `Поменяли hosts и всё супер` | Изменение файла `hosts` для сопоставления имён и IP |
| `s` | Пометка (вероятно, «start» / «server») |

## Теория

### HTTP (HyperText Transfer Protocol)

**HTTP** — протокол прикладного уровня, используемый для передачи гипертекстовых документов
в веб. Он работает по модели «запрос-ответ»: клиент отправляет запрос, сервер возвращает ответ.

Основные методы HTTP:

| Метод | Назначение |
|-------|------------|
| `GET` | Получение ресурса |
| `POST` | Отправка данных на сервер |
| `PUT` | Обновление ресурса |
| `DELETE` | Удаление ресурса |

### Веб-сервер в Linux

В Linux чаще всего используется веб-сервер **Apache** или **Nginx**. Он слушает порт **80** (HTTP)
или **443** (HTTPS) и раздаёт файлы из директории сайта.

Пример конфигурации Apache (Astra Linux / Debian):
```
DocumentRoot /var/www/html
```

Пример конфигурации Nginx:
```nginx
server {
    listen 80;
    server_name adv-server;
    root /var/www/html;
    index index.html;
}
```

### Файл hosts

Файл `/etc/hosts` сопоставляет IP-адреса и имена компьютеров. Это локальная таблица
разрешения имён, которая проверяется раньше DNS.

Пример записи:
```
192.168.1.10   adv-server
192.168.1.20   advc1
192.168.1.21   advc2
```

Когда в файле указано *«Поменяли hosts и всё супер»* — это означает, что после добавления
соответствующих записей клиенты смогли обращаться к серверу по имени, а не только по IP-адресу.

### Перезапуск службы

После изменения конфигурации веб-сервера необходимо перезапустить службу:
```
sudo systemctl restart apache2   # или nginx
```

### Схема работы

1. Сервер настроен на обработку HTTP-запросов.
2. Клиент обращается к серверу по имени (`http://adv-server`).
3. Файл `hosts` на клиенте сопоставляет имя `adv-server` с IP-адресом сервера.
4. Сервер отвечает, отдавая веб-страницы.

## Вывод

Файл фиксирует процесс развёртывания HTTP-сервера: настройку конфигурации, перезапуск службы
и проверку доступности с клиента через разрешение имён (файл `hosts`). Это шаг к построению
полноценной веб-инфраструктуры в рамках лабораторного курса.
