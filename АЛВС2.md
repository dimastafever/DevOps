# АЛВС2 — Настройка hostname и сетевого интерфейса

## Что находится в файле

Файл `АЛВС2.docx` содержит материалы по настройке имени хоста (hostname) и сетевых интерфейсов
в Linux. Содержимое файла:

```
astra-hostname
Enp1s0
S
3
2
3
```

Ключевые элементы:

| Элемент | Описание |
|---------|----------|
| `astra-hostname` | Команда настройки hostname в Astra Linux |
| `Enp1s0` | Имя сетевого интерфейса (Ethernet, предсказуемое имя) |
| `S`, `3`, `2`, `3` | Пометки/шаги выполнения лабораторной |

## Теория

### Hostname (имя хоста)

**Hostname** — это сетевое имя компьютера, по которому он идентифицируется в локальной сети.
Оно используется для:

- разрешения имён в DNS,
- отображения в командной строке (`user@hostname:~$`),
- связи между машинами в сети.

В Astra Linux настройка hostname выполняется командой:
```
sudo hostnamectl set-hostname <имя>
```
или файлом `/etc/hostname`:
```
sudo nano /etc/hostname
```

Проверить текущее имя:
```
hostname
hostnamectl
```

### Сетевые интерфейсы в Linux

**Сетевой интерфейс** — это точка подключения компьютера к сети. Каждый интерфейс имеет уникальное
имя в системе.

В старых системах Linux имена интерфейсов были простыми: `eth0`, `eth1`, `wlan0`. Начиная с
systemd/предсказуемых имён сетевых интерфейсов (Predictable Network Interface Names) имена стали
генерироваться на основе физического расположения устройства.

**`Enp1s0`** — пример предсказуемого имени. Разберём его по частям:

| Часть | Значение |
|-------|----------|
| `En` | Ethernet-интерфейс (**E**ther**n**et) |
| `p1` | Номер шины PCI (port 1) |
| `s0` | Номер слота (slot 0) |

Такие имена стабильны и не меняются при перезагрузке, в отличие от `eth0`/`eth1`, которые
могут назначаться в зависимости от порядка обнаружения устройств.

### Просмотр и настройка интерфейсов

Посмотреть все сетевые интерфейсы:
```
ip link
ip a
```

Настроить IP-адрес вручную (для Astra Linux / Debian-подобных — файл `/etc/network/interfaces`):
```
auto enp1s0
iface enp1s0 inet static
    address 192.168.1.10
    netmask 255.255.255.0
    gateway 192.168.1.1
```

Применить изменения:
```
sudo ip link set enp1s0 up
sudo systemctl restart networking
```
