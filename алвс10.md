## Теория

### Go (Golang)

**Go** — язык программирования, разработанный в Google. Он широко используется для
создания серверных приложений, микросервисов, инструментов DevOps. Его особенности:

- **Компилируемость** — программа собирается в один бинарный файл, который легко
  разворачивать на сервере.
- **Конкурентность** — встроенная поддержка горутин (goroutines) для параллельной работы.
- **Простота** — небольшой синтаксис и быстрая компиляция.
- **Стандартная библиотека** — богатый набор готовых пакетов.

Установка Go в Linux:
```
# Скачивание архива (пример для версии 1.21)
wget https://go.dev/dl/go1.21.0.linux-amd64.tar.gz

# Распаковка в /usr/local
sudo tar -C /usr/local -xzf go1.21.0.linux-amd64.tar.gz

# Добавление в PATH
export PATH=$PATH:/usr/local/go/bin

# Проверка
go version
```

> Фраза *«Потом уже распаковываем»* в файле относится именно к этому шагу — распаковке
> скачанного архива Go.

### Grafana

**Grafana** — платформа с открытым исходным кодом для визуализации и анализа данных.
Она позволяет строить интерактивные дашборды, графики и оповещения на основе данных
из разных источников (Prometheus, Loki, Elasticsearch, базы данных).

Графану обычно разворачивают как веб-приложение, которое слушает порт **3000**.

Установка Grafana:
```
sudo apt-get install -y software-properties-common
sudo add-apt-repository "deb https://packages.grafana.com/oss/deb stable main"
sudo apt-get update
sudo apt-get install grafana
sudo systemctl enable grafana-server
sudo systemctl start grafana-server
```

> ⚠️ *«В новой графане всё по другому»* — упоминание о том, что интерфейс и
> конфигурация Grafana меняются между версиями, и документация/настройки со временем
> устаревают.

### Loki

**Loki** — система агрегации логов от Grafana Labs. В отличие от полнотекстовых поисковых
систем (например Elasticsearch), Loki индексирует только **метаданные логов** (метки),
а сами сообщения хранит отдельно. Это делает её эффективной и менее ресурсоёмкой.

Loki работает в связке с **Promtail** (сборщик логов на узлах) и **Grafana**
(визуализация). Стек «Loki + Promtail + Grafana» даёт возможность:

1. Собирать логи с серверов.
2. Хранить их централизованно.
3. Просматривать и анализировать в веб-интерфейсе.
4. Строить оповещения по логам.

### Git и перенос проекта

Фраза *«как это всё на гит заливать + потом на ноут выгружать»* относится к
использованию системы контроля версий **Git** (и сервисов вроде GitHub/GitLab).
Типичный процесс:

```
git init
git add .
git commit -m "первый коммит"
git remote add origin <URL репозитория>
git push -u origin main
```

А на другом компьютере (ноутбуке) проект «выгружается» (клонируется):
```
git clone <URL репозитория>
```
