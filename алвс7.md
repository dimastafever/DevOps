# алвс7 — Настройка клиента в локальной сети

подключается к серверу и использует его ресурсы.

## Теория

### Роль клиента в сети «клиент-сервер»

В архитектуре «клиент-сервер» компьютер может выступать в одной из двух ролей:

- **Сервер** — предоставляет ресурсы (файлы, веб-страницы, IP-адреса) и услуги.
- **Клиент** — запрашивает и потребляет эти ресурсы.

В лабораторной работе клиенты `advc1` и `advc2` подключаются к серверу `adv-server`.

### Настройка клиента

Для корректной работы клиента в локальной сети нужно:

1. **Задать имя машины** (hostname).
2. **Настроить сетевой интерфейс** (получить IP-адрес — статически или через DHCP).
3. **Указать DNS-сервер** (файл `/etc/resolv.conf` или через DHCP).
4. **Добавить записи в `/etc/hosts`** (при необходимости).
5. **Проверить связь с сервером** (`ping`).

Пример настройки клиента через `/etc/network/interfaces`:
```
auto enp1s0
iface enp1s0 inet dhcp
```

или статический адрес:
```
auto enp1s0
iface enp1s0 inet static
    address 192.168.1.20
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameservers 192.168.1.10
```

### Проверка подключения

После настройки клиента проверяется доступность сервера:
```
ping adv-server
```

И доступ к сетевым ресурсам, например общему SMB-каталогу:
```
smbclient //adv-server/advsmb -U adv
```
