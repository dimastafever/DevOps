# алвс6 — Учётная запись и завершение сеанса

## Что находится в файле

Файл `алвс6.docx` содержит фрагменты работы с учётной записью пользователя и завершением сеанса.

Содержимое файла:

```
exit
3
Ss
Zxvzccnbbymmkqwk
```

Ключевые элементы:

| Элемент | Описание |
|---------|----------|
| `exit` | Команда завершения текущего сеанса/выхода из оболочки |
| `Ss` | Сокращение (вероятно, «sudo su» / «server» / имя пользователя) |
| `Zxvzccnbbymmkqwk` | Сгенерированный пароль (случайный набор символов) |
| `3` | Шаг лабораторной работы |

## Теория

### Команда exit

**`exit`** — команда завершения сеанса работы в оболочке. Она:

- закрывает текущую сессию,
- завершает работу интерпретатора,
- возвращает код возврата (по умолчанию `0` — успех).

В контексте SSH-сессии `exit` разрывает соединение с удалённым сервером:
```
ssh adv@192.168.1.10
# ... работа на сервере ...
exit
```

### Пароли и их генерация

**`Zxvzccnbbymmkqwk`** — пример сгенерированного пароля. Хорошие пароли:

- содержат случайные символы (строчные/заглавные буквы, цифры, спецсимволы),
- не связаны с личной информацией,
- достаточно длинны.

Сгенерировать надёжный пароль в Linux можно командами:
```
openssl rand -base64 16
pwgen -s 16
```

### Смена пользователя (su / sudo)

Если `Ss` интерпретировать как работу с привилегиями, то:

- **`su`** — переключение на другого пользователя (например, `su -` переключает на root).
- **`sudo`** — выполнение команды от имени суперпользователя.

Пример:
```
sudo -i   # получить root-оболочку
exit      # вернуться к обычному пользователю
```

## Вывод

Файл фиксирует работу с учётной записью: вход/выход из сеанса (`exit`), обращение с паролем
и возможное переключение привилегий. Это важный элемент администрирования — корректное
завершение сеансов и безопасное хранение паролей.
