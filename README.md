# DevOps — Лабораторные работы (АлВС)

Данный репозиторий содержит серию лабораторных работ по курсу **DevOps** и
**администрированию Linux** (Astra Linux / Debian-подобные системы). В нём
последовательно рассматриваются настройка сетевой инфраструктуры, служб,
системы контроля версий и современных инструментов оркестрации.

## Темы, охваченные курсом

Курс построен как последовательность работ, в которых одна и та же
инфраструктура «сервер + клиенты» (adv-server, advc1, advc2) развивается от базовой
настройки до полноценного облачного стека.

1. **Создание пользователей и распределение ролей** — `adduser`, sudo, архитектура
   «клиент-сервер».
2. **Настройка сети** — hostname, сетевые интерфейсы, IP-адресация.
3. **Файловые ресурсы** — SMB/Samba, открытие портов 445/139.
4. **Автоматическая выдача адресов** — DHCP-сервер (`dhcpd`).
5. **Веб-сервер** — HTTP/Apache/Nginx, разрешение имён через `hosts`.
6. **DNS** — BIND, конфигурация зон, `/etc/resolv.conf`.
7. **Клиенты** — подключение к серверу, проверка доступности.
8. **Удалённый доступ** — SSH, ключи, безопасность.
9. **Контроль версий** — Git: индексация, stash, отмена действий, ветки,
   конфликты, rebase и merge.
10. **Инструменты разработки и мониторинга** — Go, Grafana, Loki.
11. **Контейнеризация** — Docker: образы, слои, многоступенчатая сборка.
12. **Оркестрация** — Kubernetes: kubeadm, CRI, pod-сети.

## Используемые технологии

- **Системы:** Astra Linux / Debian, командная оболочка bash
- **Сетевые службы:** Samba (SMB), DHCP, HTTP (Apache/Nginx), DNS (BIND), SSH
- **Система контроля версий:** Git
- **Языки и инструменты:** Go, Grafana, Loki, Ansible
- **Контейнеризация и оркестрация:** Docker, Kubernetes (kubeadm)

## Как пользоваться

1. Откройте любой `.md`-файл — в нём описано, что находится в соответствующем
   `.docx`-файле, и дана теоретическая справка по теме.
2. Изучайте работы последовательно (от `АЛВС1` до `алвс13`), так как каждая
   следующая работа опирается на предыдущую.
3. Для запуска приведённых скриптов используйте Linux-окружение (реальное или
   виртуальную машину).

## Заключение

Репозиторий представляет собой полный учебный курс по DevOps: от настройки
базовой сетевой инфраструктуры на Linux до развёртывания контейнерных
приложений и Kubernetes-кластера.
