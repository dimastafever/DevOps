## Что находится в файле

протокола сетевого доступа к файлам и принтерам, а также настройке **DHCP** (Dynamic Host
Configuration Protocol) — службы автоматической выдачи IP-адресов.

## Теория

### SMB (Server Message Block)

**SMB** — протокол прикладного уровня для доступа к файлам, принтерам и другим сетевым ресурсам.
Широко используется в сетях Windows, а также поддерживается Linux через службу **Samba**.

Протокол SMB использует два ключевых порта:

| Порт | Назначение |
|------|------------|
| **139** | Традиционный порт NetBIOS Session Service |
| **445** | Основной порт SMB (прямое соединение без NetBIOS) |

Для работы SMB-сервера необходимо, чтобы эти порты были открыты в файрволе:
```
sudo ufw allow 139/tcp
sudo ufw allow 445/tcp
```

В файле показано, как менялось отображение сетевого ресурса `/advsmb` на клиентах
при включении этих портов — без открытых портов клиенты не видят ресурс.

### Samba

Samba — Linux-реализация протокола SMB. Конфигурация хранится в `/etc/samba/smb.conf`.
Пример общего ресурса:

```ini
[advsmb]
   path = /srv/advsmb
   browseable = yes
   read only = no
   guest ok = yes
   writable = yes
```

Перезапуск службы после изменения конфигурации:
```
sudo systemctl restart smbd
```

### DHCP (Dynamic Host Configuration Protocol)

**DHCP** — протокол автоматической выдачи сетевых параметров клиентам:

- IP-адрес,
- маску подсети,
- шлюз по умолчанию,
- адреса DNS-серверов.

**`dhcpd`** — демон DHCP-сервера в Linux. Основной конфигурационный файл:
```
/etc/dhcp/dhcpd.conf
```

Пример настройки:

```conf
subnet 192.168.1.0 netmask 255.255.255.0 {
    range 192.168.1.100 192.168.1.200;
    option routers 192.168.1.1;
    option domain-name-servers 192.168.1.10;
    default-lease-time 600;
    max-lease-time 7200;
}
```

Запуск:
```
sudo systemctl enable isc-dhcp-server
sudo systemctl start isc-dhcp-server
```

### Взаимодействие SMB и DHCP в лабораторной

В лабораторной работе DHCP-сервер выдаёт клиентам IP-адреса. Клиенты по этим адресам
подключаются к SMB-серверу и получают доступ к общему ресурсу `/advsmb`. Для этого
необходимо:

1. Настроить DHCP-сервер на выдачу адресов.
2. Настроить SMB-сервер и открыть порты 139 и 445.
3. Убедиться, что клиенты видят ресурс.
